Market data

Works with Databento downloads (the .zip as it arrives, or the CSV files inside it; OHLCV-1m or OHLCV-1s), FirstRate Data, and any CSV with time,open,high,low,close,volume columns. You can pick several files at once, like one per year. 1-second files are combined into 15-second bars. If a file holds several contract months, the app keeps the most active contract each day. Imported data replaces the sample for that instrument and stays in this browser only. Don't upload market data files to your public GitHub repo, because data licenses don't allow sharing them.
