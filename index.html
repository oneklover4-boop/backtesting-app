Market data

To use your imported data on another device, like your iPad: press Save data file here, send the file to the other device (AirDrop works), then press Open data file there and pick it.

Works with Databento downloads (the .zip as it arrives, or the CSV files inside it; OHLCV-1m or OHLCV-1s), FirstRate Data, and any CSV with time,open,high,low,close,volume columns. You can pick several files at once, like one per year. 1-second files are combined into 15-second bars. If a file holds several contract months, the app keeps the most active contract each day. Imported data replaces the sample for that instrument and stays in this browser only. Don't upload market data files to your public GitHub repo, because data licenses don't allow sharing them.

    Full screen on iPad

    Safari leaves full screen when you drag down, and a website can't stop that. Add Tape Replay to your Home Screen instead. It then opens like an app, with no Safari bars, and stays full screen.

    1. Tap the Share button at the top of Safari (a square with an arrow). If you don't see it, tap the ••• button first.
    2. Tap Add to Home Screen, then tap Add.
    3. Close Safari and open Tape Replay from your Home Screen.

    The Home Screen app keeps its own data, separate from Safari. Open your data file in it once (Sessions, then Market data, then Open data file).
